# 🚀 AI Notes Summarizer

An AI-powered web application that summarizes text and PDF documents using NLP.

---

## 🔥 Features

- ✨ Text Summarization
- 📄 PDF Summarization
- 🔊 Text to Speech
- 🔐 User Authentication (Login/Signup)
- 📥 Download Summary as PDF

---

## 🛠️ Tech Stack

- Python (Flask)
- Transformers (HuggingFace - BART)
- HTML, CSS
- SQLite
- PyPDF2
- ReportLab
